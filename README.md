# music-player-ui
Beginner UI/UX music player project designed in Figma


Music Player UI
A very beginner UI/UX project built in Figma

Purpose
The purpose of this project was to design a simple
music player interface where users can find and explore music, search for genres, play songs and manage their playlists

Screens

Home
The home screen shows
Recently Played, Made For You, Trending Now and provides navigation
![Home](screenshots/home.png)

Search
The search screen provides a search bar, browse all, and genre categories
![Search](screenshots/search.png)

Now Playing
The now playing screen displays album art, song, progress bar, play/pause buttons, shuffle/repeat options
![Now Playing](screenshots/now-playing.png)

Library
The library shows liked songs, playlists and provides navigation
![Library](screenshots/library.png)
